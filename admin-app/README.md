# پنل مدیریت (admin-app)

وب‌اپ React مستقل برای مدیریت اپ آزمون مربیگری — جدا از اپ اصلی.

## ساختار

- سورس: `admin-app/src/` — ورود، نمای کلی، کاربران (اعطا/لغو اشتراک)، سفارش‌ها، نظرها، اعلان‌ها
- خروجی بیلد: `admin-app/../admin/` — همان پوشه‌ای که سرور Express روی `/admin` سرو می‌کند (`vite.config.js` ← `base: '/admin/'` + `outDir: '../admin'`)

## توسعه

```bash
# سرور API را اول بالا بیاور (پورت ۳۰۰۱)
node server/index.js

# سپس dev server پنل (پورت ۵۱۷۴، با پراکسی /api)
cd admin-app && npm install && npm run dev
```

## انتشار

```bash
cd admin-app && npm run build   # خروجی در app/admin قرار می‌گیرد
```

- خروجی بیلد `admin/` در گیت کامیت می‌شود تا بدون بیلد هم `/admin` کار کند؛ بعد از هر تغییر دوباره بیلد بگیر.
- در دیپلوی داکر، Dockerfile خودش `admin-app` را می‌سازد و `admin/` را به ایمیج منتقل می‌کند — نیازی به کامیت خروجی نیست ولی ضرری هم ندارد.
- دسترسی فقط با حساب `admin: true` — اندپوینت‌ها همان `/api/admin/*` هستند.

## نکته امنیتی

پنل روی وب عمومی در دسترس است؛ پسورد اکانت مدیر پیش‌فرض (`1111`) را حتماً قبل از انتشار عوض کن.
